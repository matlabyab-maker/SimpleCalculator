# ماشین حساب ساده

یک ماشین حساب سبک فارسی با HTML، CSS و JavaScript؛ بدون نیاز به نصب کتابخانه یا ابزار ساخت.

## اجرا
فایل `index.html` را در مرورگر باز کنید.

## انتشار در GitHub Pages
1. فایل‌های این پروژه را در مخزن GitHub بارگذاری کنید.
2. در مخزن وارد **Settings → Pages** شوید.
3. در بخش Build and deployment، گزینه **Deploy from a branch** را انتخاب کنید.
4. شاخه `main` و پوشه `/ (root)` را انتخاب و ذخیره کنید.

این پروژه یک وب‌اپ ساده است و برای ساخت APK اندروید طراحی نشده است.
